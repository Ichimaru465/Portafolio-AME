Cuaderno del Curso

Registro de aprendizaje, prácticas y avance académico organizado por semanas.

Semana 01

Fundamentos Web

Soluciones web, Tecnologías web, Funcionamiento de la web.
Semana 02

Diseño de Interfaces (UI/UX)

HTML5, XML, CSS3, Flexbox/Grid, Diseño Responsivo y SEO.
Semana 03

Bootstrap y Tailwind CSS

Framework de diseño y utilidades de CSS para el desarrollo web moderno.
Semana 04

JavaScript y Typescript

Lenguajes de programación para el desarrollo web dinámico.
Semana 05

Framework JS (React) - HTML5, CSS3, XML, SEO

Desarrollo de aplicaciones web modernas con React.

Trabajo grupal sobre HTML5, CSS3, XML y SEO.
Semana 06

Framework JS: Eventos y Consumos de APIs

Gestión de eventos y comunicación con servicios web.
Semana 07

Framework JS: React Hooks

Utilización de Hooks para gestionar el estado y el ciclo de vida en componentes funcionales.
Semana 09

Tecnología Web Backend

Arquitectura web, servidores, server-side, PHP y JSP. Laboratorio: despliegue backend.
Semana 10

Lenguaje Python

Sintaxis, estructuras de datos, funciones, POO, excepciones y módulos.
Semana 11

Introducción a Django

MVC/MTV, URLs, vistas, plantillas y modelos de datos.
Semana 12

Formularios, Admin y Sesiones

Validación, Django Admin, middleware, autenticación y autorización.
Semana 13

Diseño de APIs RESTful

REST, serialización, filtrado, paginación, AJAX, CSRF y CORS.
Semana 14

Microservicios en Django

Arquitectura, Docker, Kubernetes, seguridad, monitoreo y consumo.
