Semana 09

Tecnología Web Backend

Arquitectura de aplicaciones web, servidores y desarrollo server-side con PHP y JSP.

Descripción del Tema

En esta semana se estudia la arquitectura de aplicaciones web desde el lado del servidor: el rol de los servidores web, el funcionamiento del server-side y los lenguajes y frameworks backend. Se analiza cómo el servidor procesa peticiones, ejecuta lógica de negocio y genera respuestas dinámicas.

También se abordan aplicaciones web con PHP y con JSP, comprendiendo el ciclo de despliegue y las diferencias entre ambos enfoques para construir soluciones backend.

Reflexión

> Entender el server-side es clave para construir aplicaciones web completas y seguras.

Esta semana refuerza la transición del frontend al backend: comprender cómo se despliegan y ejecutan aplicaciones PHP y JSP permite conectar la lógica del servidor con la experiencia del usuario y preparar la base para frameworks más avanzados.
