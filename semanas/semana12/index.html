Formularios, Admin y Sesiones

Validación, Django Admin, middleware, autenticación y autorización.

Descripción del Tema

Gestión de formularios en Django: creación, plantillas, validación y sanitización de datos con validadores. Se trabaja también Django Admin: registro de modelos, personalización, campos calculados y formularios personalizados.

Se estudian middleware y sesiones, el manejo de estado del usuario, autenticación y autorización para construir sistemas web backend más seguros y administrables.

Laboratorio 12

Desarrollo de un sistema web backend con formularios, admin, sesiones y control de acceso.

Reflexión

> Validar datos y controlar sesiones es tan importante como mostrar la interfaz.

Formularios bien validados, un admin útil y un flujo de autenticación claro elevan la calidad del backend y reducen riesgos de seguridad en aplicaciones reales.
